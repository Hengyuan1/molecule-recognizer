# Molecule Recognizer

[English](README.md) | [简体中文](README.zh-CN.md) | [한국어](README.ko.md) | Русский | [Français](README.fr.md)

Распознавайте молекулярные структуры на скриншотах, в статьях и на веб-страницах, преобразуйте их в SMILES, исправляйте результат в интерактивном редакторе и создавайте трёхмерные координаты для сохранения или копирования в формате XYZ. Приложение предназначено для задач вычислительной химии.

**Версия [0.3.0](https://github.com/Hengyuan1/molecule-recognizer/releases/tag/v0.3.0)** — Портативное приложение для Windows со встроенной OSRA и приложение на Python для Linux. [Скачать для Windows](https://github.com/Hengyuan1/molecule-recognizer/releases/download/v0.3.0/MolRecognizer-0.3.0-windows-x64.zip).

![MolRecognizer: исходное изображение, редактируемая 2D-структура и расположенная рядом 3D-модель](docs/media/UI-demo.png)

Дважды щёлкните по созданной 3D-модели в области предпросмотра, чтобы сравнить её с 2D-структурой. Перетаскивайте разделитель для изменения ширины панелей; редактор и строка SMILES остаются доступными.

Это руководство описывает установку и повседневную работу. Подробности реализации, разработки и выпуска приведены в [английском README](README.md) и документах по ссылкам ниже. Переведена документация, а не интерфейс приложения: названия кнопок и меню оставлены на английском, как в программе.

## Использование в Windows

### Портативный EXE: без установки Python, Conda и WSL

1. Скачайте [MolRecognizer-0.3.0-windows-x64.zip](https://github.com/Hengyuan1/molecule-recognizer/releases/download/v0.3.0/MolRecognizer-0.3.0-windows-x64.zip) (159 МиБ).
2. Распакуйте **весь ZIP** в постоянную папку с коротким путём и правом записи, например `C:\Users\YourName\Apps`. Избегайте глубоко вложенных каталогов.
3. Запустите `MolRecognizer.exe` из распакованной папки `MolRecognizer`.
4. Сохраняйте вместе `_internal`, `tools`, EXE рабочего процесса и все сопутствующие файлы. **Нельзя переносить только основной EXE или запускать его прямо из ZIP.** При желании создайте ярлык на этот EXE.

Требования: **Windows 10/11 x64** и .NET Framework 4.x для захвата экрана. В комплект входят **OSRA 2.2.4**, словари, DLL, среда Python/Qt/RDKit и заранее скомпилированный инструмент захвата. Отдельная установка OSRA и запуск сценариев PowerShell для портативной версии не нужны. MolScribe и веса его модели не включены.

Для обновления закройте приложение, распакуйте новую версию в отдельную папку, проверьте её и измените путь в ярлыке. Не смешивайте файлы разных версий.

### Какой архив скачивать и как проверить его

- `MolRecognizer-0.3.0-windows-x64.zip` — готовое приложение для Windows. Обычному пользователю нужен именно этот файл.
- `MolRecognizer-0.3.0-sources.zip` — исходный код **той же версии** приложения и зависимостей, патчи и инструкции сборки для разработчиков. Это не старая версия, и для запуска приложения архив не требуется.
- `.zip.sha256` — контрольная сумма соответствующего ZIP для проверки повреждений или изменений при скачивании.
- Автоматические архивы GitHub “Source code” не являются приложением и не заменяют `sources.zip`, содержащий исходники зависимостей.

Откройте PowerShell в папке с ZIP и файлом контрольной суммы:

```powershell
Get-FileHash .\MolRecognizer-0.3.0-windows-x64.zip -Algorithm SHA256
Get-Content .\MolRecognizer-0.3.0-windows-x64.zip.sha256
```

Сравните значения SHA-256. Совпадение не является цифровой подписью и не гарантирует безопасность. Приложение не подписано, поэтому Windows может показать предупреждение. Проверяйте источник загрузки; **не отключайте антивирус и не обходите правила безопасности вашей организации**.

Опубликованные ZIP совпадают с протестированными файлами. Некоторые документы внутри сохраняют статус “not published”, зафиксированный при сборке. Последующая публикация отражена на [странице релиза](https://github.com/Hengyuan1/molecule-recognizer/releases/tag/v0.3.0). Тег `v0.3.0` указывает на исходники конкретной сборки; `main` также содержит более новые изменения документации.

### Запуск из исходников в PowerShell

Пропустите этот раздел, если используете портативный EXE. Можно работать в обычном Windows Python или в разрешённой корпоративной среде Conda без WSL.

При необходимости установите Git и uv:

```powershell
winget install --id Git.Git -e
winget install --id astral-sh.uv -e
```

Заново откройте PowerShell и получите исходники:

```powershell
git clone --branch main https://github.com/Hengyuan1/molecule-recognizer.git
cd molecule-recognizer
```

Если Git недоступен, скачайте ZIP исходников ветки `main`, распакуйте его и перейдите в папку с `pyproject.toml`. Выберите один способ установки.

**Вариант A — редактируемая установка как инструмент uv, с запуском из любой папки.**

```powershell
uv tool install --python 3.11 --editable .
uv tool update-shell
```

Заново откройте PowerShell и запустите:

```powershell
molrecognizer
```

Не удаляйте папку исходников: редактируемая установка использует её напрямую. Если переместите папку, переустановите инструмент из нового расположения.

**Вариант B — Conda / Miniconda.**

```powershell
conda create -n molrecognizer python=3.11 -y
conda activate molrecognizer
python -m pip install -e .
molrecognizer
```

В новых терминалах сначала выполняйте `conda activate molrecognizer`, затем `molrecognizer`.

**Для разработки:** вместо установки инструмента можно выполнить `uv sync --python 3.11` и затем `uv run molrecognizer` в папке репозитория.

### Подключение OSRA к исходной Windows-версии

Установка из исходников **не устанавливает OSRA автоматически**. Используйте полный Windows-комплект OSRA либо папку `MolRecognizer\tools\osra` из уже распакованного портативного приложения. Сохраняйте DLL, словари и остальные файлы вместе. См. [инструкцию сборки OSRA](packaging/windows/OSRA-BUILD.md) на английском.

Укажите реальный путь в текущем сеансе PowerShell:

```powershell
$env:OSRA_EXECUTABLE = "C:\path\to\OSRA\bin\osra.exe"
& $env:OSRA_EXECUTABLE --version
molrecognizer
```

При использовании OSRA из портативного приложения путь заканчивается на `MolRecognizer\tools\osra\bin\osra.exe`. Чтобы сохранить настройку для следующих сеансов:

```powershell
[Environment]::SetEnvironmentVariable(
    "OSRA_EXECUTABLE",
    "C:\path\to\OSRA\bin\osra.exe",
    "User"
)
```

После этого откройте PowerShell заново. Можно задать переменную только для выбранной среды Conda:

```powershell
conda activate molrecognizer
conda env config vars set OSRA_EXECUTABLE="C:\path\to\OSRA\bin\osra.exe"
conda deactivate
conda activate molrecognizer
```

### Захват экрана и масштабирование в Windows

Оставьте фокус клавиатуры в MolRecognizer, переместите указатель на экран ноутбука или нужный внешний монитор и нажмите **Alt+Y** либо **Ctrl+Shift+S**. Нарисуйте прямоугольник; его можно перемещать и изменять за края или углы. **Enter / Recognize** запускает распознавание, **Esc / правая кнопка / Cancel** отменяет захват. Стрелки перемещают область на 1 пиксель, со Shift — на 10. Также доступна кнопка **Screenshot**.

В обычной Windows эти сочетания **не глобальные**: фокус должен оставаться в приложении. За один раз захватывается один монитор. Для смены экрана отмените захват, перенесите указатель и начните заново.

Портативная версия использует готовый скомпилированный инструмент. Python-версия компилирует C#-помощник через Windows PowerShell и `Add-Type`, что может быть запрещено корпоративной политикой. Snipaste не требуется. Если захват заблокирован, используйте разрешённый инструмент и откройте сохранённую картинку через **Open Image**.

После завершения перетаскивания между мониторами окно автоматически подстраивается. **A− / A+** справа внизу меняют размер интерфейса; нажатие на процент возвращает рекомендуемый масштаб экрана, а **Fit** заново подбирает размер окна. Настройки сохраняются отдельно для каждого монитора.

### Дополнительно: WSL2 / WSLg

WSL — альтернативный способ запуска Linux-приложения, **не обязательное условие для EXE или Conda в Windows**. Используйте его только там, где это разрешено.

В Ubuntu/WSL2 с WSLg выполните Linux-инструкции ниже, установив **Linux-версии OSRA и Python/uv внутри WSL**, затем запускайте `molrecognizer` из терминала Ubuntu. Не указывайте Linux-приложению Windows-файл `osra.exe`.

WSLg предоставляет **глобальное сочетание Windows Alt+Y**, пока приложение работает, если Windows-помощник запускается и сочетание не занято другой программой. Захватывается Windows-монитор под указателем. Нужны взаимодействие с PowerShell и разрешение на запуск помощника. Меню и панель повторного распознавания WSLg отображаются внутри главного окна, чтобы уменьшить проблемы с отдельными всплывающими окнами.

## Использование в Linux

Linux-версия — приложение на Python с локальной OSRA, которому нужна графическая среда. Примеры Bash рассчитаны на Ubuntu/Debian; для других дистрибутивов используйте соответствующие пакеты.

### Установка OSRA

Если ваш дистрибутив предоставляет пакет OSRA:

```bash
sudo apt update
sudo apt install git osra
osra --version
```

Доступность и версия пакета зависят от дистрибутива и могут отличаться от OSRA 2.2.4 в Windows-комплекте. Уже установленную рабочую OSRA можно продолжать использовать. Пример собственного пути:

```bash
export OSRA_EXECUTABLE="/path/to/OSRA/bin/osra"
"$OSRA_EXECUTABLE" --version
```

Замените путь реальным. Для будущих терминалов добавьте строку `export` в `~/.bashrc` или файл запуска вашей оболочки. Если подходящего пакета нет, получите исходники и инструкции у [проекта OSRA](https://sourceforge.net/projects/osra/).

### Установка и запуск MolRecognizer

Нужен **Python 3.10 или новее**; примеры используют 3.11. Для варианта с uv сначала [установите uv](https://docs.astral.sh/uv/getting-started/installation/), затем получите исходники:

```bash
git clone --branch main https://github.com/Hengyuan1/molecule-recognizer.git
cd molecule-recognizer
```

**Вариант A — редактируемый инструмент uv.**

```bash
uv tool install --python 3.11 --editable .
uv tool update-shell
```

Откройте новый терминал и запускайте из любой папки без активации среды:

```bash
molrecognizer
```

Сохраняйте папку исходников; после её перемещения переустановите инструмент.

**Вариант B — виртуальная среда pip.** Требуется Python 3.10+ с поддержкой `venv`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
molrecognizer
```

В следующих терминалах сначала активируйте ту же среду:

```bash
source /path/to/molecule-recognizer/.venv/bin/activate
molrecognizer
```

**Для разработки:** `uv sync --python 3.11`, затем `uv run molrecognizer` из репозитория. Из другой папки:

```bash
uv run --project /path/to/molecule-recognizer molrecognizer
```

### Захват экрана в Linux

При фокусе в приложении перенесите указатель на нужный экран и нажмите **Alt+Y / Ctrl+Shift+S**. В безрамочной панели Qt можно нарисовать, переместить и изменить область; Enter подтверждает, Esc отменяет. Обычная Linux-версия не регистрирует глобальные сочетания захвата.

- **X11:** сначала используется захват Qt, обычно без дополнительных пакетов. `scrot` — необязательный резервный вариант.
- **Wayland:** результат зависит от разрешений рабочего стола и композитора. `grim` работает с совместимыми композиторами, но не является универсальным решением для Wayland. Также пробуется установленный `gnome-screenshot`.
- Если захват не работает, показывает чёрный экран или неверное изображение, сохраните область штатным инструментом рабочего стола и используйте **Open Image**.

Установите только подходящий резервный инструмент:

```bash
# Резервный вариант для X11
sudo apt install scrot

# Для совместимого композитора Wayland
sudo apt install grim
```

При запуске через WSLg используйте инструкции захвата Windows из раздела о WSLg выше.

## OSRA и дополнительные зависимости

Установка из исходников автоматически устанавливает RDKit, PySide6, Pillow и NumPy (`numpy<2`); см. [pyproject.toml](pyproject.toml). OSRA — отдельная нативная программа, не Python wheel: `pip` и `uv sync` её не устанавливают. Портативная Windows-версия уже включает OSRA.

Явно заданная `OSRA_EXECUTABLE` имеет приоритет и должна указывать на рабочую программу. Без этой настройки поиск выполняется так:

- **Windows-портативная версия:** `tools/osra/bin` рядом с EXE, затем `.tools/osra/bin`, затем `PATH`.
- **Python из исходников:** `PATH`, затем `.tools/osra/bin` и `tools/osra/bin` в каталоге проекта.

Пример установки внутри проекта; в Windows замените `osra` на `osra.exe`:

```text
.tools/osra/
├── bin/
│   ├── osra
│   └── необходимые библиотеки и другие файлы
└── share/
    ├── chain.txt
    ├── spelling.txt
    └── superatom.txt
```

Если все три словаря найдены в `share/osra`, `share` или `bin` выбранной установки OSRA, приложение автоматически передаёт их абсолютные пути. Это исключает зависимость от текущего каталога. Остальные файлы среды выполнения также нужно сохранять.

### Необязательный backend MolScribe

Выберите команду для той среды, которую действительно используете:

```bash
# Среда разработки uv
uv sync --extra molscribe

# Редактируемый инструмент uv: из каталога исходников
uv tool install --python 3.11 --editable --with molscribe --with huggingface-hub .

# Активированная среда pip / Conda
python -m pip install -e ".[molscribe]"
```

Установка дополнительных зависимостей не меняет OSRA как распознаватель по умолчанию. Явно задайте `backend="molscribe"` в Python API. При первом использовании могут скачиваться веса модели. Для GPU также нужен совместимый PyTorch с поддержкой CUDA. Эти команды не добавляют MolScribe в уже собранный портативный EXE.

## Распознавание, редактирование и экспорт

1. Используйте **Open Image** или захват экрана для изображения одной молекулы. **Load SMILES** работает и без OSRA.
2. Сравните 2D-структуру и SMILES с оригиналом: проверьте обозначения атомов, замыкание циклов, порядки связей, заряды и стереохимию. Успешная проверка валентности не гарантирует правильность распознавания. При нескольких структурах загружается первый допустимый результат.
3. Исправьте результат вручную или сравните альтернативы через **Retry recognition**. Undo/Redo сохраняет связи между атомами и стереоинформацию.
4. Нажмите **Render** для создания 3D-координат. Двойной щелчок по предпросмотру открывает сравнение рядом с 2D; разделитель меняет ширину панелей. В 3D левая кнопка с перетаскиванием вращает модель, правая перемещает, колесо масштабирует.
5. После изменения 2D-структуры снова нажмите **Render**, чтобы обновить 3D-результат.
6. **Copy / Export** работают со SMILES; **Save xyz / Copy xyz** сохраняют или копируют полный текст XYZ. В списке единиц можно выбрать Angstrom (Å, по умолчанию) или Bohr.

**View → Fit structure** подгоняет только 2D-вид, не меняя координаты и расположение связей. **Format** пересчитывает 2D-размещение, **Clean** очищает рабочую область. Кнопка **Fit** справа внизу подбирает размер самого окна — это отдельная операция.

### Повторное распознавание сложных структур

После завершения или ошибки первого распознавания используйте **Retry recognition**. Программа сравнивает три локальных варианта OSRA на изображении исходного разрешения: адаптивный порог, интерпретацию 100 dpi и порог серого 0.35. Оценки не являются процентом точности и не выбирают результат автоматически.

Нажимайте **Use selected**, только если хотите заменить текущую структуру. **Keep current / Esc** оставляют внесённые изменения. **Stop retries** прекращает новые попытки, сохраняя готовые варианты для просмотра. Замену можно отменить одной операцией Undo. После принятия результата заново выполните Render перед экспортом XYZ.

Каждая из трёх попыток ограничена 15 секундами обработки OSRA и 10 секундами дополнительного времени для процесса — суммарно до 75 секунд; отмена доступна в любой момент. Все варианты могут оказаться неверными. Более чёткий снимок исходного PDF или векторного рисунка обычно полезнее простого увеличения маленького PNG.

### Инструменты и отображение

- **Select:** щелчок по атому меняет элемент, перетаскивание перемещает; перетаскивание на пустом месте выделяет область; группу можно двигать целиком. Щелчок по связи циклически меняет её порядок.
- **Bond:** выбор Single/Double/Triple/Wedge/Dash. Щелчок по атому добавляет связанный атом, перетаскивание создаёт связь. Сплошные и штриховые клиновидные связи отображают стереохимию.
- **Atom / Eraser:** добавление или замена атомов / удаление атомов и связей, в том числе массовое после выделения.
- **Ring:** бензольное или 6-, 5-, 4-, 3-членное кольцо на атоме, связи либо отдельно; перетаскивание задаёт ориентацию.
- **Charge ⊕/⊖ / PT:** изменение формального заряда / выбор элемента в периодической таблице.
- **Undo / Redo:** отмена и восстановление атомов, связей, связности, координат и стереометок.
- Ароматические системы показаны в форме Кекуле с одинарными и двойными связями. Обычные O–H и N–H свёрнуты в OH, NH, NH₂ и подобные обозначения без изменения данных молекулы и SMILES. Водороды с изотопными метками, атомным мэппингом, зарядом или стереометками остаются явными.
- Сохраняются координаты, распределение одинарных/двойных связей и клиновидные обозначения из OSRA для сопоставления с рисунком. Ошибки распознавания требуют ручной правки. Format пересчитывает размещение и проверяет стереоинформацию, но не заменяет сверку с оригиналом.
- Колесо масштабирует 2D-холст, средняя или правая кнопка с перетаскиванием перемещает его. Закрытие панели сравнения возвращает полный 2D-холст.

## Конфиденциальность и временные файлы

Распознавание выполняется локально, без загрузки изображений на сайт NCI OSRA. Windows-инструмент захвата хранит экран и область в памяти, не создавая файл скриншота. Резервные инструменты командной строки Linux могут использовать временный PNG, удаляемый после чтения. Временные изображения распознавателя удаляются после обработки.

Оригинал остаётся в памяти для Retry recognition до замены изображения, очистки рабочей области или закрытия приложения. Повторные попытки используют исходные пиксели, а не миниатюру. Временный PNG повторного распознавания удаляется при завершении, ошибке или отмене.

## Python API

Примеры предназначены для среды с установленным Python-пакетом и распознавателем, а не для непосредственного выполнения внутри EXE:

```python
import molrecognizer

# Изображение в SMILES или объект молекулы с координатами
smiles = molrecognizer.recognize("molecule.png")
mol = molrecognizer.recognize_to_molecule("molecule.png")
print(smiles, mol.num_atoms, mol.num_bonds)

# Преобразование SMILES и проверка валентности
mol = molrecognizer.smiles_to_molecule("CCO")
print(molrecognizer.molecule_to_smiles(mol))
print(molrecognizer.check_valence(mol))
```

Необязательный режим MolScribe на GPU:

```python
smiles = molrecognizer.recognize(
    "molecule.png", backend="molscribe", device="cuda"
)
```

Дополнительные примеры программного редактирования молекул — в [английском описании API](README.md#python-api).

## Решение проблем

- **Команда `molrecognizer` не найдена:** для uv выполните `uv tool update-shell` и откройте терминал заново; для Conda/venv активируйте нужную среду. В Linux проверьте путь через `command -v molrecognizer`.
- **OSRA не найдена:** в Windows проверьте `$env:OSRA_EXECUTABLE` и `Get-Command osra.exe`, в Linux — `command -v osra` и `printenv OSRA_EXECUTABLE`. Старая переменная окружения может перекрывать встроенную OSRA.
- **Нет словаря или DLL:** восстановите весь комплект и проверьте `chain.txt`, `spelling.txt`, `superatom.txt`. Не переносите EXE отдельно.
- **Горячая клавиша захвата не работает:** в Windows/Linux проверьте фокус, в WSLg — разрешения помощника и занятость сочетания. Можно открыть через Open Image снимок, сделанный другим разрешённым инструментом.
- **Интерфейс слишком крупный или мелкий:** используйте **Fit / A− / A+** на соответствующем мониторе.
- **Ошибка дисплея или плагина Qt в Linux:** запускайте в рабочем графическом сеансе или WSLg и проверьте системные библиотеки Qt. Терминал без графической среды не может показать GUI.
- **Неверная структура:** обрежьте чёткое изображение до одной молекулы, сравните варианты и проверьте результат вручную. У OSRA есть известные ошибки распознавания стереохимии.

Журнал находится в `~/.molrecognizer/molrecognizer.log` в Linux или `%USERPROFILE%\.molrecognizer\molrecognizer.log` в Windows и обновляется при каждом запуске. В [сообщении об ошибке](https://github.com/Hengyuan1/molecule-recognizer/issues) укажите версию, шаги воспроизведения и пример, которым можно публично делиться. Не прикладывайте конфиденциальные исследовательские изображения или личные журналы.
